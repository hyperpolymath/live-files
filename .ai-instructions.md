# Live-Files: RSR 2026 Control Plane

You are an agent operating on the Hyperpolymath Epistemic Fleet. 
This repo contains the orchestration logic for all satellite and core repos.

## Structural Rules
- **Tiers**: Repos are organised into Core, Governance, Infrastructure, SSG, MCP, and Research.
- **Filing**: Use \`just file\` to move root-level repos into their correct tiers.
- **Restoration**: Use \`must restore\` to fix symlinks and directory structures.
- **Visibility**: Use \`just v\` to see a two-ply colour-coded map.

## Standards
- No Makefiles. Use Just/Nickel.
- Oxford British English only.
- Prioritise nerdctl for all container tasks.
